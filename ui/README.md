# ui

Open the URL of the [PathSnap server](../api/README.md) in a browser. The viewer shows raw GPS points, candidate roads and the selected road segments. Use the layer controls for comparison, drag to pan, and use Fit to reset the map. The map is drawn from trip geometry and works without internet map tiles.

Switch between the classifier and Viterbi views to inspect their selections. Student test scores appear when aligned labels are available. Route pieces count the segments of the decoded sequence separated by gaps or infeasible transitions.
